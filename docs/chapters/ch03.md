# Chapter 3: GitHub and a self-hosted runner

Goal: a runner on the VM that picks up jobs from this private repo.

## Steps

1. On the VM, in the repo folder, pull the latest code:

        git pull

2. Install the runner as a service (label devsecops):

        ./host/install-runner.sh OWNER/REPOSITORY

3. In GitHub: Settings, Actions, Runners. The runner must show Idle.
4. Run the hello workflow (Actions tab, hello, Run workflow). It prints the
   runner name, branch, Docker and Python versions.

## Done when

The hello run is green and the log shows your VM's name.

## Safety

The repo stays private while the runner is attached.
