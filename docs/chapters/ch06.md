# Chapter 6: Image scanning and SBOM with Trivy

Goal: the pipeline builds the Juice Shop image, scans it for known vulnerabilities and produces a software bill of materials (SBOM).

## Steps

1. Start the VM; the runner shows Idle.
2. Copy the stage file over the pipeline, commit and push:

        Copy-Item stages\pipeline-ch06.yml .github\workflows\pipeline.yml
        git add .github\workflows\pipeline.yml stages\pipeline-ch06.yml
        git commit -m "ch06: add Trivy image scan and SBOM"
        git push

3. Actions, pipeline run: the summary shows Gitleaks, Semgrep and Trivy (image severities, top CVEs, 733 components in the SBOM).
4. Follow one finding: CVE-2015-9235 in jsonwebtoken 0.4.0 (fixed in 4.2.2).
5. Tag and push: git tag ch06, git push --tags. Stop the VM (deallocate).

## What the pipeline does

- Builds the Juice Shop image from the checked-out tag.
- Runs Trivy on the image: JSON report plus table, and an SBOM (component list).
- Prints severity counts and the top CVEs on the run summary page.
- Report only: the job stays green. The gate comes in chapter 7.

## Notes

- Image findings include OS packages and app dependencies; a CVE is a lead, not a verdict (is the code path reachable?).
- The SBOM answers "what is inside this image?" when the next CVE is announced.

## Done when

The run summary lists the Trivy counts and top CVEs, and the SBOM component count is shown.
