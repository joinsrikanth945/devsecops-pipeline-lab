# Chapter 2: the lab host on Azure

Goal: one Ubuntu 24.04 VM with Docker, reachable only over SSH from your
own IP address.

Cost: Standard_F2as_v6 is about 0.146 USD an hour while it runs. Stop
(deallocate) it when you are not working, and keep auto-shutdown on.

## Steps

1. Create an SSH key on your PC (PowerShell). Create the folder first if it
   does not exist. The private key stays on your PC; only the .pub file is
   shared with Azure.

        New-Item -ItemType Directory -Force "$env:USERPROFILE\.ssh"
        ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\devsecops-lab" -N '""'
        Get-Content "$env:USERPROFILE\.ssh\devsecops-lab.pub" | Set-Clipboard

2. In the Azure portal create a virtual machine:
   - Name devsecops-lab, region Sweden Central, Ubuntu Server 24.04 LTS
     (x64), user azureuser, SSH public key source "Use existing public key"
     (paste the key from step 1).
   - Size: Standard_D2s_v5 may show "Insufficient quota" on a new account.
     Click "Find deployable options" and pick Standard_F2as_v6 (2 vCPUs,
     8 GiB). Later chapters (DefectDojo, Kafka) need 16 GiB; resize then.
   - Inbound ports: SSH (22) only.
   - Disk: 64 GiB. This size uses NVMe, so use Premium SSD.
   - Management: turn Auto-shutdown on and pick a time in your time zone.
3. Restrict SSH to your own IP: VM, Networking, click the SSH rule, set
   Source to "IP Addresses" and enter your public IP (search "what is my
   IP"), then Save. If your IP changes later, update this rule.
4. Log in from your PC:

        ssh -i "$env:USERPROFILE\.ssh\devsecops-lab" azureuser@VM_PUBLIC_IP

5. On the VM, install git and the GitHub CLI and sign in. The VM is a
   separate computer, so it needs its own GitHub login (a one-time code that
   you approve at github.com/login/device).

        sudo apt-get update && sudo apt-get install -y gh git
        gh auth login
        gh repo clone OWNER/REPOSITORY
        cd YOUR-REPOSITORY

6. Install Docker with the host script, then log out and back in so the
   docker group applies:

        bash host/setup-host.sh
        exit

7. Log in again (step 4) and test:

        docker run --rm hello-world

## Done when

"Hello from Docker!" is printed without sudo.

## Stop paying

Portal: VM, Stop. Wait until the status is Deallocated. Shutting down from
inside Linux does not stop the charge. Delete the resource group
(devsecops-lab_group) only after you have finished the whole series.
